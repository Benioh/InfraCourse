## 路线建议

- **0 GPU 路线**：重点完成 `docs/前置体检清单.md`、源码调用链、notebook、配置审查、report/self-check；所有性能结论写 `validation-only`。
- **1×4090 路线**：优先跑 L00/L01/L01.5/L02/L07/L08/L10/L10.5 的 smoke，训练扩展类 lab 以小模型和边界说明为主。
- **8×H200 路线**：重点补 L04/L05/L09/L11 的真实性能与扩展实验，并把命令、配置、metrics 与 checkpoint 全部归档。

## 报告要求

无论哪条路线，`report.md` 都必须写清：硬件模式、是否真实运行、哪些结论只能迁移为假设、下一步需要什么最小实验验证。
