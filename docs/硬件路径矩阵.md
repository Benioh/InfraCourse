本矩阵说明 0 GPU、1×RTX 4090、8×H200 三种条件下，每关可以完成到什么程度。百分比不是成绩，而是"课程目标可验证度"：源码研读、notebook、配置审查可以在无 GPU 下完成；真实性能、扩展和 RL 闭环必须标注硬件边界。

## 路线建议

- **0 GPU 路线**：完成 `docs/前置体检清单.md`、源码调用链、notebook、配置审查、report/self-check；
  **强烈推荐先把 6 个 ✦ 新 lab 全部跑过**——它们 100% CPU 可完成，把 RL Infra 真实生产事故的对策完整建立起来。所有性能结论写 `validation-only`。
- **1×4090 路线**：优先跑 L00/L01/L01.5/L02/L07/L08/L10/L10.5 + 6 个 ✦ 新 lab 的 smoke；训练扩展类 lab 以小模型和边界说明为主。
- **8×H200 路线**：重点补 L04/L05/L09/L11 的真实性能与扩展实验，并把命令、配置、metrics 与 checkpoint 全部归档。同时把 6 个 ✦ 新 lab 在真实硬件上验证（K3 KL 真长跑、CUDA IPC handle tuple 真集群同步、CUDA Graph 真录制重放、chunked GAE 实测加速比等）。

## 报告要求

无论哪条路线，`report.md` 都必须写清：硬件模式、是否真实运行、哪些结论只能迁移为假设、下一步需要什么最小实验验证。

v2 lab（✦/✦✦）的 CPU 模拟版本**保证结构性不变量与生产 GPU 版本一致**（handle tuple 是元数据、graph buffer 复用、stack 聚合归因等），但**不证明性能数字**——把数字结论放到真实硬件验证后再写进报告。
