# 自学使用指南（Patch Track 重写版）

> 这门课的核心：**每关写一个能跑过单元测试的真补丁，并能把这个 patch 放回真实框架源码主线**。patch-test 验证代码；AI 框架理解口试验证你真的读懂了系统边界。

## 单关闭环（每关都一样）

```bash
# 1. 读 task.md（patch 契约入口）
cat labs/<lab>/patch/task.md

# 2. 跑前置 notebook + 读源码
cat labs/<lab>/quiz.yaml | grep -A1 "kind: notebook\|kind: source"
# 浏览器打开对应文件

# 3. 通过 quiz gate（5 题全对才算"学懂"）
# 在 app 里点 "Start quiz"，或 curl POST /api/missions/<lab>/quiz
# quiz 全对会写入 .quiz_passed.json

# 4. 改 starter 代码
$EDITOR labs/<lab>/patch/starter/<file>.py

# 5. 跑测试 PASS = 代码不变量通过
make patch-test M=<lab>

# 6. 用 AI 做框架理解口试
# 打开 prompts/framework_understanding_tutor.md，把 mission、task、source_reading、
# patch 摘要和测试输出发给 AI；直到它判定“框架理解通过”

# 7. 卡住时三级提示
make patch-hint M=<lab>             # 看 TODO 列表 + 关键提示
make patch-show-solution M=<lab>    # 看完整参考解
```

pytest 全绿只说明 patch contract 通过；进入下一阶段前，还需要能通过 `docs/AI框架理解评估指南.md` 定义的源码理解口试。

## 学习节奏

每关大约 **2-4 小时**：
- 30 min — 读 task.md + 跑前置 notebook + 读源码
- 15 min — 通过 quiz（5 题概念检验）
- 60-180 min — 实际写 patch
- 5 min — 跑 patch-test
- 15-30 min — AI 框架理解口试，补齐源码主线误区

**节奏太赶？** 不要求一次过 quiz，可以重答；但 patch 必须自己写过一遍才看 reference。

## 卡住怎么办（按顺序尝试）

| 症状 | 操作 |
|---|---|
| 看不懂 task.md 接口契约 | 先打开对应 notebook（task.md 顶部链接），把概念图画一遍 |
| starter 里 TODO 不知怎么填 | `make patch-hint M=<lab>` 看 TODO 列表 + 关键提示 |
| 跑 patch-test 报 shape/数值错 | 用 print 在 forward 里打张量 shape/dtype/device，与 task.md 契约逐项核对 |
| 30+ 分钟仍卡 | `make patch-show-solution M=<lab>` 打开参考解。**建议先关掉再自己写一遍** |
| patch-test 通过想精进 | 打开 `github_repo/<framework>/` 真实工程版，比对你写的与生产版 3 处差异 |

## 进入下一关的硬性门槛

- `make patch-test M=<lab>` 全绿 = 代码不变量通过
- AI 框架理解口试通过 = 源码主线理解通过
- 没有 quiz gate（前 N 题答对）也能跑 patch，但 UI 会显示 "🔒 强制运行（不推荐）"
- 软门槛但视觉强提醒，目的是让你诚实学

## 全课终点

L12 Capstone 三档：
- **Bronze**：实现 projector + WER + clip score 三个组件，patch-test 7/7
- **Silver**：跑通 Stage A + Stage B（projector 训练 + endpoint 部署）
- **Gold**：跑通 Stage A/B/C（加 RL 对齐，post-RL +5pp 提升）

写一份 5–8 页 capstone 报告附 3 张你改过的真实框架 diff 截图，简历直接能用。

## AI 协作守则

AI 是 copilot，不是 oracle：

```
Observe → Ask → Patch Plan → Human Check → Apply → Test → Explain → Commit
```

禁止让 AI 静默改框架、跳过 pytest、绕过断言。每个 patch 必须自己理解每一行——
quiz gate 就是为此存在的"诚实自检"。
