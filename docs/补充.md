六、Profiler 与性能分析
1. torch profiler

用于看：

PyTorch op 耗时；
CPU / CUDA 时间；
op shape；
是否有大量小 op；
memory 使用情况。
2. nsys / Nsight Systems

用于看：

CPU-GPU timeline；
GPU 是否空闲；
kernel launch 间隔；
NCCL 通信；
计算和通信是否 overlap；
不同 rank 是否负载不均。
3. torch memory profiler

用于看：

显存是谁分配的；
OOM 发生前的分配历史；
activation / optimizer state / gradient 占用；
是否有 tensor 没释放；
是否保存了计算图。

4. 常见问题定位

包括：
